# CRM Desktop для микро-бизнеса

Легковесное десктопное приложение для управления клиентами, товарами, продажами и обращениями. Создано на базе NeutralinoJS с использованием веб-технологий, что обеспечивает низкие системные требования, кроссплатформенность и высокую скорость работы.

## Возможности

### Основные модули
| Модуль | Функционал |
|--------|-----------|
| **Клиенты** | Карточки клиентов, сегментация (Потенциальный/Обычный/VIP), история покупок, контакты |
| **Товары** | Каталог с категориями, автогенерация SKU, управление остатками, статусы |
| **Продажи** | Регистрация сделок, списания, поступления, привязка к клиентам, периодические операции |
| **Обращения** | Поддержка клиентов, типы (Вопрос/Жалоба/Заказ), статусы, приоритеты |
| **Календарь** | Заметки по датам, интеграция с клиентами/продажами/обращениями, цветовые метки |
| **Аналитика** | 8+ интерактивных графиков (Chart.js), фильтрация по периоду, экспорт данных |

### Технические преимущества
- **Локальное хранение**: IndexedDB — данные не покидают устройство
- **Автономная работа**: не требует интернета после установки
- **Бэкапы**: экспорт/импорт в JSON одним кликом
- **Аудит-лог**: журнал всех операций с возможностью восстановления
- **Темы оформления**: синяя (по умолчанию) и зелёная (Excel-стиль)
- **Адаптивный интерфейс**: корректное отображение на разных разрешениях

## Стек технологий

| Слой | Технология | Назначение |
|------|-----------|-----------|
| **Runtime** | NeutralinoJS | Десктопная оболочка, доступ к файловой системе, нативное меню |
| **Frontend** | HTML5, CSS3, Vanilla JS (ES6+) | Интерфейс без тяжелых фреймворков, быстрая загрузка |
| **Визуализация** | Chart.js + date-fns | Интерактивные графики и диаграммы |
| **База данных** | IndexedDB | Локальное хранилище с асинхронным доступом |
| **Утилиты** | Neutralino FileSystem API | Бэкапы, настройки, логирование |
| **Сборка** | Neu CLI + Inno Setup | Создание `.exe` установщика для Windows |

## Начало работы

### Требования
- [Node.js](https://nodejs.org/) (LTS версия, 18+)
- Git
- Windows 10/11 (для сборки `.exe`)

Проверка установки:
```bash
node -v
git --version
```

### Установка

```bash
# 1. Клонирование репозитория
git clone https://github.com/ваш-логин/ваш-репозиторий.git
cd ваш-репозиторий

# 2. Установка зависимостей
npm install

# 3. Глобальная установка Neutralino CLI
npm install -g @neutralinojs/neu
```

### Запуск в режиме разработки

```bash
neu run
```

Приложение откроется с включённой консолью разработчика (инспектором).

#### Управление режимом отладки

В файле `neutralino.config.json` найдите секцию `modes.window`:

```json
"window": {
  "title": "CRM System",
  "width": 1200,
  "height": 800,
  "enableInspector": true,  // ← true = режим разработки, false = продакшн
  ...
}
```

## Сборка дистрибутива (Windows)

### Шаг 1: Сборка ресурсов

```bash
neu build --release
```

Оптимизированные файлы появятся в `bin/crm-app/`.

### Шаг 2: Создание установщика (.exe)

1. **Установите [Inno Setup](https://jrsoftware.org/isdl.php)**
2. **Скомпилируйте скрипт:**

```cmd
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer/installer.iss
```

1. **Готовый файл**: `output/installer/CRM-Setup-x.x.x.exe`

## Настройки и конфигурация

### Файл настроек: `crm_data/settings.json`

```json
{
  "ui": {
    "showTooltips": true,
    "darkMode": false,
    "showNavText": true,
    "animateRows": true,
    "selectionModifier": "shift",
    "theme": "blue"
  },
  "calendar": {
    "canEditSchedule": true,
    "workDays": { "0": true, "1": true, "2": true, "3": true, "4": true, "5": false, "6": false }
  },
  "logging": {
    "cleanupStrategy": "none",
    "maxEntries": 1000,
    "maxAgeDays": 90
  }
}
```

### Темы оформления

Доступны две темы, переключаемые в настройках:

| Тема | Описание |
|------|----------|
| `blue` | Синяя (по умолчанию), современный корпоративный стиль |
| `excel` | Зелёная, вдохновлена интерфейсом Microsoft Excel |

Темы реализованы через CSS-переменные — переключение происходит мгновенно без перезагрузки.

## Работа с данными

### Экспорт / Импорт

- **Экспорт**: Все данные сохраняются в `crm_data/backup.json`
- **Импорт**: Загрузка резервной копии через интерфейс настроек
- **Аудит-лог**: `crm_data/logs.json` — журнал всех операций (создание/изменение/удаление)

### Структура БД (IndexedDB)

```
CRM_Database (v6)
├── clients          # Клиенты
├── products         # Товары
├── sales            # Продажи и корректировки
├── tickets          # Обращения
├── bulk_adjustments # Периодические операции
└── calendar_notes   # Заметки календаря
```

## Тестирование

### Генератор тестовых данных

Для стресс-тестирования используйте встроенный скрипт:

```bash
python generate_test_data.py --clients 100 --products 100 --sales 100 --tickets 100 --notes 50
```

Параметры:
- `--clients`, `--products`, `--sales`, `--tickets`, `--notes` — количество записей
- `--output` — путь к файлу (по умолчанию `crm_data/backup.json`)

### Проверка производительности

| Операция | 100 записей | 1000 записей |
|----------|-------------|--------------|
| Загрузка страницы | < 0.5 сек | < 2 сек |
| Применение фильтра | < 0.3 сек | < 1 сек |
| Экспорт бэкапа | < 1 сек | < 5 сек |

## Устранение неполадок

| Проблема | Решение |
|----------|---------|
| **Белый экран при запуске** | Проверьте, что `resources/` находится в корне проекта; очистите кэш браузера |
| **Данные не сохраняются** | Убедитесь, что у приложения есть права на запись в `crm_data/`; проверьте консоль на ошибки IndexedDB |
| **Графики не отображаются** | Убедитесь, что `chart.min.js` находится в `resources/lib/`; проверьте консоль на ошибки загрузки скриптов |
| **Медленная работа с большими данными** | Используйте фильтрацию; включите ленивую загрузку в `main.js` |
| **Не применяется тема** | Проверьте значение `ui.theme` в `settings.json`; перезагрузите приложение |
