# Быстрый старт в Лад CRM

> Легковесная CRM для микробизнеса. Все данные хранятся локально, работа без интернета.

---

## Клиенты

**Управление базой клиентов с автоматической сегментацией**

### Возможности:
- Автоматическая сегментация: **VIP**, **Лояльные**, **Новые**, **Риск ухода**, **Неактивные**
- Поиск по имени, телефону или email (поддержка цифр телефона)
- История покупок и **RFM-анализ** (Recency, Frequency, Monetary)
- Экспорт списка клиентов в CSV

### Как использовать:
1. Нажмите **«Добавить клиента»** → заполните имя и контакт
2. Система автоматически рассчитает сегмент на основе покупок
3. Используйте фильтры для быстрого поиска нужной группы

> Совет: Сегменты обновляются автоматически при добавлении продаж.

---

## Товары

**Каталог продукции с контролем остатков**

### Возможности:
- Учёт остатков с предупреждением о **низком запасе** (настраиваемый порог)
- Автоматическое списание при продажах
- Категории товаров (можно добавлять свои)
- Генерация SKU (артикула) по шаблону `КА-123`
- Экспорт каталога в CSV

### Как использовать:
1. Добавьте товар с категорией, ценой и начальным остатком
2. При продаже остаток уменьшится автоматически
3. Настройте порог низкого остатка в настройках (по умолчанию: 20)

> Внимание: При попытке продать больше, чем есть на складе, система покажет предупреждение.

## 🎫 Обращения

Регистрация входящих запросов

### Возможности:
- Типы обращений: Вопрос, Жалоба, Заказ, Предложение, Претензия
- Статусы: **Открыта** → **Выполнена** → **Архив**
- Привязка к клиенту (опционально)
- Поиск по тексту описания

### Как использовать:
1. Зафиксируйте обращение: кто, как связаться, суть
2. Назначьте статус при решении
3. Используйте фильтры для работы с открытыми запросами

## Продажи

**Журнал сделок с автоматическим пересчётом**

### Возможности:
- Транзакционная целостность: продажа = списание товара + обновление метрик клиента
- Поддержка нескольких товаров в одном чеке
- Типы операций: Продажа (-), Списание (-), Поступление (+)
- Фильтрация по дате, клиенту, товару, типу
- Детали чека по клику на количество

### Как использовать:
1. Нажмите «Единичная сделка» → выберите клиента и товары
2. Система автоматически пересчитает остатки и метрики клиента
3. Просмотр деталей чека: кликните на число в колонке «Кол-во»

> Безопасность: Все операции сохраняются в локальную БД с резервным копированием.

## Отчёты

Аналитика и экспорт данных

### Возможности:
- Воронка продаж по статусам
- Статистика клиентов по сегментам
- Конверсия между этапами
- Экспорт в **CSV** (открывается в Excel) и **JSON**

### Как использовать:
1. Выберите период и тип отчёта
2. Нажмите **«Экспорт»** для сохранения
3. Используйте данные для принятия решений

## Настройки

Конфигурация системы

### Возможности:
- Темы оформления: Синяя, Зелёная (Excel), 1С, Корпоративная
- Пароль на вход в приложение
- Импорт/экспорт данных (CSV, JSON, SQLite)
- Резервное копирование при каждом изменении
- Настройка уведомлений и логирования

### Как использовать:
1. Откройте «Настройки» → выберите нужный раздел
2. Изменения применяются мгновенно (кроме пароля — требуется перезапуск)

> Безопасность: Пароль хранится в хешированном виде (SHA-256).

## Календарь

Планирование задач и событий

### Возможности:
- Отображение маркеров: Клиенты, Продажи, Обращения
- Цветовое кодирование заметок
- Редактирование расписания (рабочие/выходные дни)
- Быстрый переход к записи по клику

### Как использовать:
1. Включите редактирование в настройках календаря
2. Кликните по заголовку дня для изменения статуса
3. Добавьте заметку для планирования

## Задачи

Канбан-доска для управления задачами

### Возможности:
- Приоритизация по матрице Эйзенхауэра:
  - Срочно и Важно
  - Не срочно, но Важно
  - Срочно, но Не важно
  - Не срочно и Не важно
- Дедлайны с визуальными маркерами
- Привязка задачи к клиенту, продаже или обращению
- Автоматические уведомления о приближении срока

### Как использовать:
1. Создайте задачу с названием и приоритетом
2. Перетаскивайте между колонками по мере выполнения
3. Нажмите кнопку для установки напоминания

## ⌨️ Горячие клавиши

| Комбинация | Действие |
|------------|----------|
| `↑` / `↓` | Переход между полями формы |
| `Tab` / `Shift+Tab` | Альтернативная навигация |
| `␣` (Пробел) | Открыть выпадающий список |
| `←` / `→` | Выбор в списке |
| `Enter` | Сохранить и закрыть |

| `Esc` | Закрыть без сохранения |

## Частые вопросы

**Где хранятся мои данные?**  
→ Все данные сохраняются локально в файл `crm_data/crm_data.sqlite` на вашем компьютере.

**Можно ли работать без интернета?**  
→ Да, приложение полностью автономно после установки.

**Как сделать резервную копию?**  
→ Нажмите **«Настройки» → «Экспорт данных»** или используйте автоматическое автосохранение.

**Что делать, если забыл пароль?**  
→ Удалите файл `crm_data/settings.json` (пароль сбросится, но остальные данные сохранятся).
